Banco de Dados Cloudflare D1

O Cloudflare D1 é o banco SQL nativo da própria Cloudflare!

Ele não requer chaves públicas no frontend. O Cloudflare Pages conecta automaticamente através de /api/devices.

Passos rápidos na Cloudflare:
  1. Crie o banco em Storage & Databases > D1 SQL Database > Create database (nome: pmoc-db).
  2. No seu projeto do Pages, vincule o banco em Settings > Functions > D1 bindings (nome: DB, banco: pmoc-db).
  3. Execute o script SQL fornecido na aba Console do D1.

Script SQL para Cloudflare D1

schema_cloudflare_d1.sql 
CREATE TABLE IF NOT EXISTS pmoc_devices (
    id TEXT PRIMARY KEY,
    tag INTEGER UNIQUE NOT NULL,
    local TEXT NOT NULL,
    setor TEXT NOT NULL,
    marca TEXT NOT NULL,
    modelo TEXT DEFAULT '',
    btu INTEGER NOT NULL DEFAULT 12000,
    data_manutencao TEXT,
    tecnico_executante TEXT DEFAULT 'Guilherme',
    aprovacao_supervisor TEXT DEFAULT 'Ismael',
    proxima_manutencao TEXT,
    observacoes TEXT DEFAULT '',
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    updated_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE IF NOT EXISTS pmoc_maintenance_history (
    id TEXT PRIMARY KEY,
    device_tag INTEGER NOT NULL,
    data_manutencao TEXT NOT NULL,
    proxima_manutencao TEXT NOT NULL,
    tecnico_executante TEXT NOT NULL,
    aprovacao_supervisor TEXT DEFAULT 'Ismael',
    observacoes TEXT DEFAULT '',
    checklist TEXT DEFAULT '{}',
    created_at TEXT DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (device_tag) REFERENCES pmoc_devices(tag) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS idx_pmoc_devices_tag ON pmoc_devices(tag);
CREATE INDEX IF NOT EXISTS idx_pmoc_devices_local ON pmoc_devices(local);
CREATE INDEX IF NOT EXISTS idx_pmoc_devices_setor ON pmoc_devices(setor);
CREATE INDEX IF NOT EXISTS idx_pmoc_devices_proxima ON pmoc_devices(proxima_manutencao);
CREATE INDEX IF NOT EXISTS idx_pmoc_history_tag ON pmoc_maintenance_history(device_tag);
